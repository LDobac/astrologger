문제 개요

난이도 - HARD 사용 언어 - C++

지난 LeetCode - 21. Merge Two Sorted Lists 문제의 확장 버전입니다.

정렬된 k개의 연결 리스트가 입력되면, 모든 연결 리스트를 정렬된 하나의 연결 리스트로 합쳐 반환합니다.

문제 - LeetCode - 23. Merge k Sorted Lists

풀이

My Solutions(Github)

Solution 1 - Merge one by one

첫 번째 해결 방법은 LeetCode - 21. Merge Two Sorted Lists의 풀이 방법을 그대로 사용해 풀어보겠습니다.

ListNode* mergeKLists(vector<ListNode*>& lists) {
    if (lists.size() == 0) return nullptr;

    ListNode* result = lists[0];

    for (size_t i = 1; i < lists.size(); i++)
    {
        result = mergeTwoLists(result, lists[i]);
    }

    return result;
}

단순히 두 연결 리스트를 병합하는 함수를 이용해 하나씩 병합하며, k - 1번 순회해 모든 연결 리스트를 연결합니다.

제출 결과

실행 속도는 296ms로, 다른 C++ 제출자에 비해 13% 정도의 성능밖에 나오지 않았습니다. 이유를 알기 위해 Big-O를 계산해보겠습니다.

각 연결 리스트를 하나씩 더하기 때문에 lists = {list_1, list_2, list_3 ... ,list_k}가 있을 때, 각 리스트의 노드 수 평균을 n개라고 해보겠습니다.

그럼 처음 merge(list_1, list_2)를 수행할 때 O(n)의 시간 복잡도가 발생합니다(길이가 n인 리스트를 순회하므로). 그리고 반환된 리스트의 길이는 2n이 됩니다. 이 리스트를 list_1m2라고 해보겠습니다.

그리고 list_1m2와 list_3에 대해서 merge(list_1m2, list_3)를 수행하면 O(2n)의 시간 복잡도가 발생합니다(길이가 2n, n인 리스트를 순회하므로 최악의 경우인 2n). 그럼 반환된 리스트 list_1m3은 길이가 3n이 됩니다.

이런 식으로 k번째까지 쭉 더하면 발생하는 반복 횟수는 n + 2n + 3n + ... + kn = n(1 + 2 + 3 + ... + k)가 됩니다.

일반적으로 1 + 2 + 3 + ... + k = k(k + 1)/2로 계산할 수 있으니 nk(k+1)/2입니다. 따라서

O(kn2)O(kn^2)O(kn2)

이 됩니다.

공간 복잡도는 입력 리스트와 관계없이 포인터 하나만 선언하므로

O(1)O(1)O(1)

입니다.

코드 전문 
class Solution {
public:
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        if (lists.size() == 0) return nullptr;

        ListNode* result = lists[0];

        for (size_t i = 1; i < lists.size(); i++)
        {
            result = mergeTwoLists(result, lists[i]);
        }

        return result;
    }

    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        if (!list1 && !list2) return nullptr;
        
        ListNode* mergedHead = nullptr;
        ListNode* lastNode = nullptr;

        ListNode* node1 = list1;
        ListNode* node2 = list2;

        while (node1 && node2)
        {
            ListNode* selectedNode = nullptr;

            if (node1->val < node2->val)
            {
                selectedNode = node1;
                node1 = node1->next;
            }
            else
            {
                selectedNode = node2;
                node2 = node2->next;
            }

            if (mergedHead == nullptr)
            {
                mergedHead = selectedNode;
            }
            else
            {
                lastNode->next = selectedNode;
            }

            lastNode = selectedNode;
        }

        if (node1)
        {
            if (!mergedHead)
            {
                mergedHead = node1;
            }
            else
            {
                for (auto node = node1; node != nullptr; node = node->next)
                {
                    lastNode->next = node;
                    lastNode = node;
                }
            }
        }

        if (node2)
        {
            if (!mergedHead)
            {
                mergedHead = node2;
            }
            else
            {
                for (auto node = node2; node != nullptr; node = node->next)
                {
                    lastNode->next = node;
                    lastNode = node;
                }
            }
        }

        return mergedHead;   
    }
};

Solution 2 - Prority Queue

두 번째 풀이 방법은 우선순위 큐, 혹은 Heap 자료구조를 이용해 풀어보겠습니다.

우선순위 큐(Heap)는 일반적으로 최댓값 혹은 최솟값을 빠르게 찾기 위해 사용되는 자료구조입니다.

현재 문제는 오름차순으로 정렬된 모든 리스트를 하나의 정렬된 리스트로 반환하는 문제이므로, 입력으로 주어진 모든 노드를 우선순위 큐에 삽입하고 빼면서 하나의 리스트로 만들면 문제를 해결할 수 있을 것입니다.

풀이에 사용되는 언어가 C++이므로 C++ STL의 priority_queue 자료구조를 사용하도록 합니다. 해당 자료구조에 대한 자세한 스펙은 연결된 링크를 참조해주세요.

auto cmp = [](ListNode* left, ListNode* right) {
    return left->val > right->val;
};

priority_queue<ListNode*, vector<ListNode*>, decltype(cmp)> queue(cmp);

우선순위 큐를 선언하고 별도의 비교 함수를 전달해, 이 우선순위 큐가 오름차순(min-heap)으로 형성되도록 합니다.

for (auto &&head : lists)
{
    for (auto node = head; node != nullptr; node = node->next)
    {
        queue.push(node);
    }
}

그리고 입력된 모든 노드를 큐에 삽입합니다.

while (!queue.empty()) 
{
    auto r = queue.top(); 
    queue.pop();

    if (!head) 
    {
        head = r;
        tail = head;
        continue;
    }

    tail->next = r;
    r->next = nullptr;
    tail = r;
}

그리고 단순히 큐에서 하나씩 pop을 수행하면서 하나의 연결 리스트로 형성합니다.

제출 결과

실행 속도는 16ms로, 97%가량의 성능이 나왔습니다.

우선순위 큐는 구현 방법에 따라 시간 복잡도가 약간씩 다르지만, 보통 삽입은

O(1)O(1)O(1)

, 삭제는

O(log(n))O(log(n))O(log(n))

으로 계산됩니다. 따라서 k개의 리스트에 대해 삽입과 삭제를 수행하므로

O(klog(n))O(klog(n))O(klog(n))

로 계산할 수 있습니다.

다만 공간 복잡도는 k개의 우선순위 큐 공간이 필요하므로

O(k)O(k)O(k)

가 됩니다.

코드 전문 
class Solution {
public:
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        if (lists.size() == 0) return nullptr;

        ListNode* head = nullptr;
        ListNode* tail = nullptr;

        auto cmp = [](ListNode* left, ListNode* right) {
            return left->val > right->val;
        };

        priority_queue<ListNode*, vector<ListNode*>, decltype(cmp)> queue(cmp);

        for (auto &&head : lists)
        {
            for (auto node = head; node != nullptr; node = node->next)
            {
                queue.push(node);
            }
        }

        while (!queue.empty()) 
        {
            auto r = queue.top(); 
            queue.pop();

            if (!head) 
            {
                head = r;
                tail = head;
                continue;
            }

            tail->next = r;
            r->next = nullptr;
            tail = r;
        }

        return head;
    }
};

Solution 3 - Divide and Conquer

세 번째 방법은 분할 정복을 이용해 성능은 최대한 유지하면서 공간 복잡도는

O(1)O(1)O(1)

로 구현해보겠습니다.

구현 자체는 간단합니다. Solution 1과 동일하게 두 연결 리스트를 병합하는 함수를 이용하지만, 병합하는 과정에서 분할 정복 기법을 사용합니다.

auto amount = lists.size();
auto interval = 1;
while (interval < amount)
{
    for (auto i = 0; i < amount - interval; i += interval * 2)
    {
        lists[i] = mergeTwoLists(lists[i], lists[i + interval]);
    }
    interval *= 2;
}

제출 결과

실행 속도는 25ms로 Solution 2와 큰 차이가 없음을 확인할 수 있습니다.

공간 복잡도도

O(1)O(1)O(1)

이기 때문에, 시간 복잡도와 공간 복잡도를 아주 적절하게 Trade-off한 것입니다.

평균 노드 개수가 n인 k개의 연결 리스트를 분할 정복 기법으로 병합하는 경우의 Big-O를 계산해보겠습니다.

출처 : https://m.blog.naver.com/PostView.naver?isHttpsRedirect=true&blogId=kks227&logNo=220776241154

분할 정복은 일반적으로 문제를 m개씩 분해합니다(여기서는 2개씩 분해합니다).

이때 이 코드는 k개의 연결 리스트를 2개씩 분할해서 병합합니다. 최대로 분할될 수 있는 단계는 logk(밑이 2인데 생략)이므로 분할의 시간 복잡도는

O(logk)O(logk)O(logk)

입니다.

이때 k개가 있으므로

O(klogk)O(klogk)O(klogk)

로 계산할 수 있습니다. 그리고 n개의 노드를 병합해야 하므로

O(n∗klogk)O(n * klogk)O(n∗klogk)

의 시간 복잡도가 계산됩니다.

Solution 1의 시간 복잡도는

O(kn2)O(kn^2)O(kn2)

이었는데 Solution 3의 시간 복잡도는

O(n∗klogk)O(n * klogk)O(n∗klogk)

이므로 당연히 더 빠르게 실행됩니다.

실제로 손으로 하나씩 계산해보면, Solution 1의 순회는 n + 2n + 3n + …으로, 병합한 두 연결 리스트의 결과인 2n에 대해 또 병합을 하기 때문에 위와 같은 결과가 나옵니다.

하지만 Solution 3은 (n + n), (n + n)… (2n + 2n), (2n + 2n)… (4n + 4n), …처럼 분할된 것들이 합쳐지면서 병합되기 때문에 최악의 경우도 nlogn밖에 되지 않습니다.

코드 전문 
class Solution {
public:
    ListNode* mergeKLists(vector<ListNode*>& lists) {
        if (lists.size() == 0) return nullptr;

        auto amount = lists.size();
        auto interval = 1;
        while (interval < amount)
        {
            for (auto i = 0; i < amount - interval; i += interval * 2)
            {
                lists[i] = mergeTwoLists(lists[i], lists[i + interval]);
            }
            interval *= 2;
        }

        return lists[0];
    }

    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        if (!list1 && !list2) return nullptr;
        
        ListNode* mergedHead = nullptr;
        ListNode* lastNode = nullptr;

        ListNode* node1 = list1;
        ListNode* node2 = list2;

        while (node1 && node2)
        {
            ListNode* selectedNode = nullptr;

            if (node1->val < node2->val)
            {
                selectedNode = node1;
                node1 = node1->next;
            }
            else
            {
                selectedNode = node2;
                node2 = node2->next;
            }

            if (mergedHead == nullptr)
            {
                mergedHead = selectedNode;
            }
            else
            {
                lastNode->next = selectedNode;
            }

            lastNode = selectedNode;
        }

        if (node1)
        {
            if (!mergedHead)
            {
                mergedHead = node1;
            }
            else
            {
                for (auto node = node1; node != nullptr; node = node->next)
                {
                    lastNode->next = node;
                    lastNode = node;
                }
            }
        }

        if (node2)
        {
            if (!mergedHead)
            {
                mergedHead = node2;
            }
            else
            {
                for (auto node = node2; node != nullptr; node = node->next)
                {
                    lastNode->next = node;
                    lastNode = node;
                }
            }
        }

        return mergedHead;   
    }
};
