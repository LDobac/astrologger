개인정보 처리방침

시행일: 2026-11-09

jaehee.dev(이하 "블로그")는 개인이 운영하는 블로그입니다. 블로그는 댓글과 조회수 기능을 위해 필요한 최소한의 정보만 처리하며, 회원가입은 없습니다.

1. 수집하는 정보와 목적, 보유 기간

항목 목적 보유 기간
닉네임, 댓글 내용 (필수, 공개) 댓글 게시 댓글이 삭제될 때까지
비밀번호 (필수) 댓글 수정·삭제 시 본인 확인. 원문은 저장하지 않고 복원할 수 없는 해시값만 저장합니다. 댓글이 삭제될 때까지
이메일 주소 (선택, 비공개) 해당 댓글에 블로그 운영자의 답글이 달릴 때 알림 메일 발송 댓글이 삭제될 때까지

이메일 주소는 입력하지 않아도 댓글을 남길 수 있으며, 이 경우 답글 알림만 받을 수 없습니다. 이메일 주소는 어떤 화면이나 API에도 공개되지 않고, 답글 알림 외의 용도(광고, 소식 발송 등)로 사용하지 않습니다.

2. 자동으로 처리되는 정보

  • 조회수 중복 방지: 같은 방문자의 조회가 하루에 여러 번 집계되지 않도록 IP 주소를 날짜별 임의값과 함께 일방향 암호화(HMAC)한 값만 저장합니다. 원래 IP 주소는 저장하지 않으며, 이 값은 날짜가 바뀌면 삭제됩니다.
  • 요청 횟수 제한: 스팸과 무차별 대입을 막기 위해 IP 주소 기준으로 짧은 시간 동안의 요청 횟수를 셉니다. IP 주소를 저장하지 않습니다.
  • 방문 통계: Google Analytics가 쿠키를 사용해 방문 기록(방문 페이지, 기기·브라우저 정보, 대략적인 위치 등)을 수집합니다. 브라우저 설정에서 쿠키를 차단하거나 Google Analytics 차단 부가기능을 사용해 거부할 수 있습니다.
  • 화면 설정: 다크 모드 설정을 브라우저의 localStorage에 저장합니다. 이 값은 서버로 전송되지 않습니다.

3. 처리 위탁 및 국외 이전

블로그는 다음 서비스를 이용하며, 각 서비스는 미국 등 국외에서 정보를 처리할 수 있습니다.

업체 업무 처리 정보
Cloudflare, Inc. 댓글·조회수 API와 데이터베이스 운영 댓글 정보(1항), 조회수 처리 정보(2항)
Google LLC 답글 알림 메일 발송(Gmail), 방문 통계(Google Analytics), 웹폰트 제공(Google Fonts) 이메일 주소와 알림 내용, 방문 기록, 접속 IP
GitHub, Inc. 웹사이트 호스팅(GitHub Pages) 접속 IP 등 접속 기록

4. 이용자의 권리

  • 댓글 작성 시 입력한 비밀번호로 언제든 댓글을 삭제할 수 있으며, 이때 닉네임, 비밀번호 해시, 이메일 주소가 함께 삭제됩니다. 운영자의 답글이 달린 댓글은 답글과 함께 삭제됩니다.
  • 비밀번호를 잊었거나 이메일 주소만 삭제하고 싶은 경우, 처리 현황 확인을 원하는 경우 아래 연락처로 요청해 주세요. 확인 후 지체 없이 처리합니다.

5. 안전성 확보 조치

  • 비밀번호는 PBKDF2-SHA256으로 해시해 저장합니다.
  • 이메일 주소는 공개 API 응답에 포함되지 않으며, 운영자만 별도 인증을 거쳐 조회할 수 있습니다.
  • 모든 통신은 HTTPS로 암호화됩니다.
